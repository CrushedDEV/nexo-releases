# Contributing to Nexo

Thanks for helping make Nexo better! The source code is private, so contributions happen through **issues**: bug reports, feature ideas and feedback are all welcome.

## Reporting a bug

1. Make sure you are on the latest version (**Settings → Check for updates**).
2. Search the [existing issues](https://github.com/CrushedDEV/nexo-releases/issues) — someone may have reported it already.
3. [Open a bug report](https://github.com/CrushedDEV/nexo-releases/issues/new?template=bug_report.yml) and include:
   - your Nexo version (shown in **Settings**) and Windows version;
   - which account types you use (Claude subscription, ChatGPT subscription, API key);
   - the exact steps to reproduce, what you expected and what happened;
   - screenshots and the error message, if any.

If the problem is with an update, attach `%TEMP%\nexo-update-splash.log`.

**Never paste API keys, tokens, passwords or private conversations** into an issue. Redact anything sensitive from screenshots and logs.

## Suggesting a feature

[Open a feature request](https://github.com/CrushedDEV/nexo-releases/issues/new?template=feature_request.yml). Describe the problem you want to solve, not only the solution — it helps find the best way to build it. Screenshots, mockups or references from other apps are very helpful.

## Security issues

Please report vulnerabilities privately, as described in [SECURITY.md](SECURITY.md).

## Code of conduct

Everyone taking part is expected to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
